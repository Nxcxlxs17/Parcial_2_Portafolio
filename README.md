# Parcial_2_Portafolio
Creación de mi Portafolio con React y Vite.

1-. Creación del proyecto React con vite - npm create vite@latest mi-app -- --template react

2-. Agregar dependencias - cd mi-app && npm install

3-. Agregar Libreria Antd Design - npm install antd

4-. Agregar dependencia para uso de Test - npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom
